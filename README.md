# 定投策略回测系统

基于GLD（黄金）、QQQ（纳斯达克100）、SPY（标普500）历史数据的定投策略回测系统。

## 项目概述

本项目回测以下定投策略：
- **每周投资额**: $2,000
- **资产配置**: 50% GLD（黄金）, 25% QQQ（纳斯达克100）, 25% SPY（标普500）
- **策略**: 买入持有（无主动交易）
- **回测周期**: 2005-2025（20年）

## 策略理念

**定投 + 买入持有**：
- 无论市场涨跌，每周固定投资$2,000
- 50%配置黄金（防御性）、25%配置科技股（成长性）、25%配置大盘（稳定性）
- 永不卖出 - 让复利长期发挥作用
- 通过持续买入自动平滑市场波动

## 核心结果（2005-2025）

从2005年开始每周投资$2,000：
- **累计投入**: $208万
- **最终价值**: ~$990万
- **净利润**: ~$782万
- **年化收益率**: ~18.8%
- **最大回撤**: ~24%

## 使用方法

### 1. 下载历史数据

```bash
python download_yahoo_data.py
```

脚本会从Yahoo Finance下载GLD、QQQ、SPY的历史价格数据，保存到`data/`目录。

### 2. 运行回测

```bash
python dca_backtest.py
```

运行后会：
- 测试从不同年份开始投资的结果（2005、2008、2010、2015、2020）
- 生成`dca_backtest_results.csv`详细结果数据
- 生成`dca_backtest_results.png`可视化图表

## 文件说明

- `download_yahoo_data.py` - 从Yahoo Finance下载历史价格数据
- `dca_backtest.py` - 主回测程序（定投买入持有策略）

## 结果解读

### 为什么选择买入持有？

经过大量测试，主动交易策略的表现持续落后：
- **买入持有**: 年化收益18.8%
- **趋势跟踪**: 年化收益<2%
- **移动止损**: 年化收益<2%

**核心洞察**：频繁交易会打断复利效应。定投+买入持有能够充分利用长期复利的力量。

### 为什么是50/25/25配置？

**50% 黄金（GLD）**：
- 防御性资产，降低组合波动
- 与股票相关性低
- 历史年化收益：~13.7%
- 起到组合稳定器作用

**25% 纳斯达克100（QQQ）**：
- 成长型科技股
- 收益最高但波动较大
- 历史年化收益：~34%
- 最大回撤：~42%

**25% 标普500（SPY）**：
- 广泛市场覆盖
- 成长与稳定兼顾
- 历史年化收益：~13.8%

**50/25/25组合**：
- 风险收益平衡
- 年化收益：~18.8%
- 最大回撤：~24%（可接受范围）

### 不同起始年份的表现

| 起始年份 | 投资年限 | 年化收益 | 最大回撤 | 累计投入 | 最终价值 |
|---------|---------|---------|---------|---------|---------|
| 2005 | 20年 | 18.8% | 24% | $208万 | $990万 |
| 2008 | 17年 | 18.2% | 24% | $177万 | $720万 |
| 2010 | 15年 | 17.2% | 22% | $156万 | $560万 |
| 2015 | 10年 | 18.2% | 18% | $104万 | $290万 |
| 2020 | 5年 | 23.5% | 9% | $52万 | $110万 |

**关键发现**：买入持有策略在所有市场环境下都表现稳定，即使从2008年金融危机或2020年疫情期间开始投资也能获得良好收益。
